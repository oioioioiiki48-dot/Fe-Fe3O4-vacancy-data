# Fe-Fe3O4-vacancy-data

This repository provides supporting data for the manuscript:

**“The effects of vacancy defects on the growth and stability of the oxide layer on bcc-iron surface.”**

## Data download

The data archives are available in **Release v1.0**.

To download the data:
1. Click **v1.0** under **Releases** on the right side of the repository homepage.
2. Expand the **Assets** section.
3. Download and extract the relevant `.tar.gz` archives.
